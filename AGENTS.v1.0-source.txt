📦 2. PROJECT OVERVIEW

SignalFlow = aplikasi trading signal untuk forex/gold/crypto yang:

· Fetch OHLCV dari Twelve Data API (auto-detect tier FREE/PRO)
· Menjalankan 5 strategi: EMA Cross, Trend Structure, MACD Cross, FVG, Order Block+BOS
· Filter dengan 4 confirmations: RSI, ATR, Volume, Order Block
· Generate signal JSON (read-only) dengan Entry/SL/TP/RR + quant score
· AI scoring sebagai second opinion (score 0-100 + verdict + reasoning)
· TradingView WebView widget untuk visual analysis (no API key needed)
· Signal journal di Room DB (SQLite)

Kombinasi rekomendasi (default preset): FVG + Order Block di M15 — dua strategi SMC yang saling melengkapi, win rate tertinggi menurut backtest spesifikasi.

🏗️ 4. ARCHITECTURE RULES (WAJIB DIPATUHI)

Android — Clean Architecture

```
presentation/ (Compose UI + ViewModel)
    ↓ hanya bisa akses
domain/ (UseCase + model read-only)
    ↓ hanya bisa akses
data/ (Repository, Remote, Local)
```

ATURAN:

· presentation TIDAK BOLEH langsung import Retrofit/Room
· domain TIDAK BOLEH import Android framework (kecuali kotlinx.coroutines)
· data adalah satu-satunya yang tahu cara komunikasi dengan backend & DB
· Semua use case = suspend fun atau Flow<T>
· ViewModel hanya boleh expose StateFlow<UiState>

Backend — Layered

```
api/ (routes, thin — hanya parse & delegate)
    ↓
services/ (business orchestration)
    ↓
strategies/ + confirmations/ + risk/ + scoring/ (pure logic, no I/O)
    ↓
clients (twelve_data_client, ai_client) — satu-satunya yang HTTP keluar
```

ATURAN:

· Route handler maksimal 15 baris
· Strategy function = pure function signature: (df: pd.DataFrame, config: dict) -> SignalDraft | None
· Semua client HTTP pakai httpx.AsyncClient (bukan requests)
· Semua response pakai Pydantic model (no raw dict)

🧮 7. STRATEGY SPECIFICATIONS

Setiap strategi = pure function. Wajib ada unit test dengan fixture CSV yang valid & tidak valid.

7.1 EMA Cross

```python
def ema_cross(df: pd.DataFrame, cfg: EmaCrossConfig) -> SignalDraft | None:
    """
    Signal LONG jika: EMA_fast cross ABOVE EMA_slow (bar sebelumnya di bawah)
    Signal SHORT jika: EMA_fast cross BELOW EMA_slow
    Konfirmasi tren: EMA_slow slope positif (LONG) / negatif (SHORT)
    Default: fast=9, slow=21, slope_window=5
    """
```

7.2 Trend Structure

```python
def trend_structure(df: pd.DataFrame, cfg: TrendStructureConfig) -> SignalDraft | None:
    """
    Deteksi swing high/low (fractal 2-kiri-2-kanan)
    LONG jika: HH + HL terbentuk ≥ 2 kali berurutan
    SHORT jika: LH + LL terbentuk ≥ 2 kali berurutan
    Break of structure (BOS) sebagai trigger entry
    Default: swing_lookback=2, min_patterns=2
    """
```

7.3 MACD Cross

```python
def macd_cross(df: pd.DataFrame, cfg: MacdConfig) -> SignalDraft | None:
    """
    LONG jika: MACD line cross ABOVE signal line DAN histogram > 0
    SHORT jika: MACD line cross BELOW signal line DAN histogram < 0
    Filter: crossover harus terjadi di area OS/OB (opsional)
    Default: fast=12, slow=26, signal=9
    """
```

7.4 Fair Value Gap (FVG)

```python
def fvg(df: pd.DataFrame, cfg: FvgConfig) -> SignalDraft | None:
    """
    Bullish FVG: low[i] > high[i-2] (gap 3-candle)
    Bearish FVG: high[i] < low[i-2]
    VALID jika candle ke-3 (i) TIDAK menutup gap > 50%
    Entry: retest ke 50% FVG level
    SL: bawah FVG low (LONG) / atas FVG high (SHORT)
    TP: RR 1:2, 1:3, 1:4
    Default: min_gap_pips=2, require_mitigation=false
    """
```

7.5 Order Block + BOS/CHOCH ⭐ (PRIORITY)

```python
def order_block_bos(df: pd.DataFrame, cfg: ObBosConfig) -> SignalDraft | None:
    """
    Order Block = candle terakhir berlawanan arah sebelum impulsive move
    BOS = Break of Structure (harga break swing high/low terakhir searah trend)
    CHOCH = Change of Character (break berlawanan trend → reversal signal)

    BULLISH SETUP:
      1. Detect last down-candle sebelum rally > (atr * 1.5)
      2. Mark OB zone = [low, high] candle tersebut
      3. Tunggu BOS: harga break swing high terakhir
      4. Entry: retest ke 50% OB zone
      5. SL: bawah OB low - buffer(0.2 * ATR)
      6. TP: swing high sebelumnya / RR 1:3

    BEARISH SETUP: mirror

    Default: impulse_atr_mult=1.5, ob_buffer_atr=0.2, require_bos=true
    """
```

🔍 8. CONFIRMATION FILTERS

Setiap filter return bool + nilai aktual untuk logging.

Filter Logic Threshold Default
RSI LONG: RSI < 70 (tidak overbought), SHORT: RSI > 30 30/70
ATR ATR/price > min_volatility_pct (hindari flat market) 0.05%
Volume Volume candle signal > MA(volume, 20) × 1.2 1.2x
Order Block Ada OB aktif di dekat entry (± 1 ATR) proximity=1.0 ATR

Gate Logic:

```
total_confluence = sum(confirmations passed)
IF total_confluence >= threshold (default 3 dari 4) → VALID
ELSE → NO_SIGNAL
```

💰 9. RISK CALCULATOR (risk/levels.py)

```python
def calculate_levels(direction, entry, structure_level, atr, cfg) -> Levels:
    """
    SL = structure_level ± (atr * cfg.sl_buffer_atr)
    TP1 = entry + (risk * 2.0)   # RR 1:2
    TP2 = entry + (risk * 3.0)   # RR 1:3
    TP3 = entry + (risk * 4.0)   # RR 1:4
    RR = (TP1 - entry) / (entry - SL)

    Return: {entry, sl, tp: [tp1, tp2, tp3], rr, risk_pips}
    """
```

Semua angka WAJIB dibulatkan sesuai pip_size pair (XAUUSD=0.01, EURUSD=0.00001, dst).

📊 10. QUANT SCORE (scoring/confluence_score.py)

Skor objektif 0–100. BUKAN AI. Deterministic.

```
Komponen:
  - Core strategy strength   : 30 poin (misal: FVG gap size, OB impulse strength)
  - Konfluensi filter count  : 25 poin (4/4→25, 3/4→18, 2/4→10, ≤1→0)
  - RR ratio                 : 20 poin (≥3→20, 2.5→15, 2→10, <2→5)
  - Trend alignment (HTF)    : 15 poin (H4/H1 searah → 15, mixed → 7, lawan → 0)
  - Volatility (ATR)         : 10 poin (sweet spot 0.05%-0.3% → 10)

Total = sum → clamp 0-100
```

Skor > 70 = high confidence; < 50 = AI bisa override ke SKIP.

Prompt Template (WAJIB pakai format JSON output)

```python
SYSTEM_PROMPT = """
You are a professional trading analyst. Given a signal with quantitative 
confluence, provide a second opinion. Output ONLY valid JSON matching:
{
  "ai_score": <int 0-100>,
  "verdict": "TAKE" | "WAIT" | "SKIP",
  "reasoning": "<2-3 kalimat>",
  "risks": ["<risk 1>", "<risk 2>"]
}

Scoring guide:
- 80-100: High probability, all confluences align
- 60-79: Good setup, minor concerns
- 40-59: Marginal, need more confirmation
- 0-39: Poor setup, avoid
"""
```

Parse Strategy

· Extract JSON via regex \{[\s\S]*\} jika response mengandung markdown
· Fallback jika parse gagal: ai_score=0, verdict="WAIT", reasoning="AI parse error"
· Retry max 2x dengan exponential backoff
· Timeout 30 detik
· Log raw response untuk debugging
